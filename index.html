Model Transparency

  • Assumption: Scores use only NPS API fields (activities, entrance fees, coordinates, pets allowed) and are scaled 0 to 100 against the parks currently being compared, so a score shows rank within this list, not an absolute grade.
  • Limitation: NPS activity data is often incomplete and doesn't account for lodging, activities fees and travel so affordability is based on entrance. Weather comes from outside API and is only displayed.
  • What it does NOT mean: A high score doesn't equate to a better trip, it does not account for closures, safety concerns, or crowds.
  • What it DOES mean: The #1 park is the best match for the activities, budget, days, and weights you chose today. Change any input or slider and the ranking can change. Confirm details on the park's NPS page before traveling.

Data sources: Live NPS API (parks and things-to-do) for National Park units only, plus Open-Meteo for weather. A park counts as pet-friendly if at least one of its NPS things-to-do entries is marked pets permitted (often only on certain trails or areas); if NPS lists no pet data for a park, it is kept. Hike and scenic counts come from NPS things-to-do entries and depend on how thoroughly each park is listed.

Park data: National Park Service API · Weather: Open-Meteo · Estimates only, always confirm details on nps.gov
